# أداة فحص أسماء Xbox الرباعية 🎮

أداة بسيطة وسهلة لفحص توفر أسماء مستخدمين رباعية على Xbox.

## المميزات ✨

- ✅ فحص أسماء مستخدمين رباعية فقط (4 أحرف)
- ✅ عرض النتائج بشكل واضح (✅ متوفر / ❌ غير متوفر)
- ✅ فحص عدة أسماء في نفس الوقت
- ✅ واجهة سهلة الاستخدام
- ✅ التحقق من صحة طول الاسم تلقائياً

## المتطلبات 📋

- Python 3.6+
- مكتبة requests

## التثبيت 🔧

```bash
# استنساخ المستودع
git clone https://github.com/ahmrf334-code/usernames-xbox.git
cd usernames-xbox

# تثبيت المكتبات المطلوبة
pip install -r requirements.txt
```

## الاستخدام 🚀

```bash
python app.py
```

ثم اتبع التعليمات:
1. أدخل أسماء المستخدمين الرباعية (واحد في كل سطر)
2. **ملاحظة: يجب أن يكون كل اسم 4 أحرف فقط**
3. اضغط Enter مرتين عند الانتهاء
4. سترى النتائج مع ✅ أو ❌

### مثال:

```
أدخل اسم مستخدم: abcd
أدخل اسم مستخدم: xyz1
أدخل اسم مستخدم: test
أدخل اسم مستخدم: 
```

**النتائج:**
```
==================================================
نتائج فحص أسماء Xbox الرباعية
==================================================

abcd                   ✅ متوفر
xyz1                   ❌ غير متوفر
test                   ✅ متوفر

==================================================
```
